# Assets

Para construir la app, añade aquí (o sustituye):

- **icon.png** – Icono de la app (1024×1024 px recomendado).
- **splash.png** – Imagen de splash (recomendado al menos 1284×2778 px).
- **adaptive-icon.png** – Icono adaptativo Android (1024×1024 px).

Si no existen, Expo puede usar iconos por defecto en desarrollo. Para producción (APK), conviene tener al menos `icon.png` y `adaptive-icon.png`.
